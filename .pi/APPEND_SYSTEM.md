This project is a SolidJS port of `@primer/react` (Primer React). When making changes, preserve the public API, accessibility behavior, styling semantics, and component composition patterns of the React implementation where practical, while adapting idiomatically to SolidJS.

We aim for a 1-1 port with complete feature parity.

The upstream Primer React repository is cloned in `react/` in this workspace and should be used as the source of truth for component behavior and dependencies.

`components.md` contains the current status of the port from react.
